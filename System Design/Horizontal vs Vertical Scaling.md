

- Horizontal Scaling

	- Adding Multiple Servers/Devices to increase processing power
	- Resilient
	-  Network calls ( RPC )
	-  Issue with Data consistency
	-  scalable


- Vertical Scaling:

	- Adding More CPU/ Memory Power to a single device,server,etc
	-  Single Point failure 
	-  Fast Inter process communication
	-  Data consistent
	-  Hardware Limit
