
**Over Fitting :**  
- When the ML prediction works perfectly well with the training data but works poorly on the testing data.
- Model Memories / learns the noise of the data instead of learning the pattern

**Under fitting:**
- The Model is not performing well on the training data as well, hence it will not work on the validation/testing data also.

**Bias:**
- Errors which occur when we try to fit a statistical model on real world data which does not fit perfectly on some mathematical models
-  When we use a simplistic model to fit the data we are in high chance to face the situation of High Bias 
- High bias - underfit

**Variance:**
- The error value that occur when we try to make predictions by using data that is not previously seen by the model
- High variance means model is not working well on the testing data 
- High Variance - Over fitting 



Finding proper balance between the two is know as Bias Variance trade-off
